### 🔭 [RETROSPECT](https://github.com/K-NagaCharan/RETROSPECT)

Evolution-aware code search. Finds a function even when you search by its **old name**, by pairing Tree-sitter search with rename lineage from Git history.

- Java, Python, JavaScript, TypeScript
- No embeddings, no vector DB
- Old-name query MRR **0.36 → 0.77** on a 42-repo test
- 📄 Paper accepted at **IEEE IC2NC 2026**
