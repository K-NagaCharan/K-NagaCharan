### Featured work

| Project | What it does | Stack |
|---|---|---|
| [**RETROSPECT**](https://github.com/K-NagaCharan/RETROSPECT) | Evolution-aware code search, published on npm as [`retrospect-cli`](https://www.npmjs.com/package/retrospect-cli). Finds a function even when you search by its old name, by pairing Tree-sitter search with rename lineage from Git history. Supports Java, Python, JavaScript and TypeScript with no embeddings or vector DB. On a 42-repo test, old-name query MRR rose from 0.36 to 0.77. Paper accepted at IEEE IC2NC 2026. | Node.js, Git, Tree-sitter |
| [**ACE: AI Context Engine**](https://github.com/K-NagaCharan/ACE-AI-Context-Engine) | CLI published on npm as [`ace-track`](https://www.npmjs.com/package/ace-track). Turns Git commit history into portable AI context, processes commits incrementally to save tokens, and works with 6+ AI providers (OpenAI, Gemini, Ollama, OpenRouter, LM Studio and more). 100% coverage on core modules. | Node.js, Jest, npm |
| [**Drishyamitra**](https://github.com/K-NagaCharan/Drishyamitra) | AI photo manager with facial recognition and a chat assistant. I built the agent loop that turns requests into Groq tool calls (search, tag, zip, send) and the React frontend. | React, Express, Groq, Redis, Socket.IO |
| [**TCS-Prep**](https://github.com/K-NagaCharan/TCS-prep) · [Live](https://tcs-prep-delta.vercel.app/) | TCS NQT verbal ability simulator. Generation and evaluation run on separate models, with automated grading and rewrite feedback. | React, Vite, Groq |
